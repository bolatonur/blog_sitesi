# Blog Sitesi

Flask kullanarak geliştirdiğimiz basit bir blog uygulaması.

Bu projeyi web geliştirme tarafını daha iyi anlamak ve özellikle bir web uygulamasının route, template ve veritabanı yapılarının birlikte nasıl çalıştığını deneyimlemek amacıyla geliştirdik.

## Kullanılan Teknolojiler

- Python
- Flask
- Jinja
- SQLAlchemy
- HTML
- CSS

## Özellikler

- Blog gönderisi ekleme
- Gönderi düzenleme
- Gönderi silme
- Dinamik içerik görüntüleme
- SQLAlchemy ile veritabanı kullanımı
- Türkçe karakterlerle uyumlu slug oluşturma
- Gönderiler için görüntülenme sayacı
- Farklı ekran boyutlarına uyum sağlayan responsive tasarım

## Proje Hakkında

Projeyi geliştirirken Flask'ın temel yapısını, route kullanımını, template sistemini ve veritabanı işlemlerini öğrenmeye çalıştık.

Karşılaştığımız sorunları araştırarak ve yapay zekâ araçlarından da destek alarak çözmeye çalıştık. 

## Responsive Tasarım

Arayüz masaüstü, tablet ve mobil ekranlara uyum sağlayacak şekilde responsive olarak geliştirildi.

## Kurulum ve Çalıştırma

Projeyi klonladıktan sonra gerekli paketleri yükleyin:

    pip install -r requirements.txt

Ardından uygulamayı çalıştırın:

    python app.py
